# 风之海 · 沉浸互动体验

一个开源的蓝色沉浸式 Web 互动舞台。你可以用鼠标、触摸或摄像头手势捏破装着白色烟雾的泡泡，也可以转动手机体验空间视差与 3D 环绕。

在线体验：<https://xiezhengru68-gif.github.io/wind-sea-interactive/>

## 体验亮点

- 烟雾泡泡：点击、触摸或捏合手指使泡泡破裂，白色云雾随即散开
- 摄像头手势：双手拉开形成云带，合拢后压成一颗回弹泡泡
- 蓝色风车：在附近捏合手指即可拿起，移动手掌带着它旋转，松开后顺势放飞；也支持鼠标和触摸拖动
- 空间环绕：鼠标、触摸与手机方向感应共同驱动多层景深
- 音乐响应：导入你有权使用的本地音频后，灯光与氛围随音乐变化
- 手机适配：支持主流移动端浏览器与触觉反馈
- 轻量字幕：仓库只包含原创场景文字，不包含受版权保护的完整歌词

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
git clone https://github.com/xiezhengru68-gif/wind-sea-interactive.git
cd wind-sea-interactive
npm install
npm run dev
```

然后打开 <http://localhost:3000>。

## 音乐与摄像头

项目不附带商业歌曲文件。进入体验后点击“本地音乐”，选择你拥有或获准使用的音频；音频只在当前浏览器中播放，不会被上传。

摄像头功能需要 HTTPS 或 localhost。手势识别在设备本地完成；关闭功能或离开页面后，摄像头轨道会被停止。

## 部署

推送到 `main` 分支后，仓库内的 GitHub Actions 会自动构建并发布到 GitHub Pages。公开体验不需要 ChatGPT 或 GPT 会员。
